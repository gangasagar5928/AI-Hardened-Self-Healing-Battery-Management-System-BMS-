The Problem

EV Batteries Are Hackable

Legacy CAN bus (ISO 11898) has zero authentication. Anyone with OBD-II access — or a nearby Bluetooth device — can spoof battery voltages, replay commands, flood the network, or disconnect the battery pack mid-ride.

Layer 4 — Adaptive EKF

Covariance-Modulated Kalman Filter

Reff = Rbase × e10 × Sanomaly
0.0
S_anomaly = 0
No attack · R_eff = R_base · K normal · Measurements trusted fully
148×
S_anomaly = 0.5
Suspicious · R_eff inflated 148× · K near zero · Measurement partially ignored
22K×
S_anomaly = 1.0
Confirmed attack · R_eff = 22,026× · K → 0 · BMS runs on pure Coulomb counting

Mathematical proof: When K → 0, x̂ = x_pred. Corrupted CAN data completely bypassed. SoC error bound: < 1.4%.

Layer 5 — Fail-Safe Response

Graceful Degradation

Attack detected → 4 simultaneous mandatory actions

🚫
Ignore Unauthorised Commands
Commands failing Auth L1/L2 or flagged by IDS are silently dropped — no error response (prevents error oracle probing).
⚡
Keep Supplying Power
Battery stays connected if hardware thresholds are safe. Only BQ76920 hardware OVP/UVP or verified Tier-2 command triggers disconnect — never IDS score alone.
🔔
Alert the Rider
OLED flashes "SECURITY ALERT" · Bluetooth push notification with attack type + timestamp · Optional GPIO 32 buzzer.
📋
Log the Event
500-event circular buffer in NVS flash. Attack type, anomaly score, CAN ID, BT MAC. Exportable via app for forensic analysis.
